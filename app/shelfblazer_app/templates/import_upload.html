How it works

  • A row with an ID updates that record; a row without one creates a new record owned by you. An export file has an ID column, so you can export, edit in a spreadsheet and import again.
  • A blank cell leaves the field as it is, so a partly filled column never wipes data. To clear a field, edit the record.
  • Next you choose what each column is (titles that match a field are chosen for you), then see every row checked with the same rules as the record form. If one row has a problem, nothing is imported: fix the file and upload it again.
  • Several options or links in one cell are separated by commas or semicolons; yes/no fields take yes or no; dates are YYYY-MM-DD.
  • Everything goes in as one commit that you can undo right afterwards.
  • At most {{ max_rows }} rows and {{ max_kb }} kB per file. Excel files must be saved as CSV or TSV first.
