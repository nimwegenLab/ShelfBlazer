Tell an AI assistant what you have, in plain words, and it enters the records for you: “Add {{ ex_a }} called …”, “Add these twenty {{ ex }}s from my table”. It checks for duplicates first and follows the lab’s conventions. It can search too: “Which {{ ex }}s did I add this month?”

Install Claude Code

If it is not on your computer yet, install it from claude.com/claude-code and sign in once. You will also need a terminal: Terminal on a Mac, PowerShell on Windows.

Create a token for this computer

Open a terminal and run these two commands, one after the other: click Copy, paste into the terminal, press Enter.

a. This one waits for the token: {% if new_token %}click Copy token above{% else %}copy the token you created in step 2{% endif %}, paste it, press Enter. Nothing appears while you paste: that is on purpose, so the token stays off the screen.

read -rs SBT

b. This one connects Claude Code to ShelfBlazer, for every folder on this computer:

claude mcp add --scope user --transport http shelfblazer {{ request.base_url }}mcp --header "Authorization: Bearer $SBT"; unset SBT

On Windows (PowerShell 7)
$env:SBT = Read-Host -MaskInput "Token"
claude mcp add --scope user --transport http shelfblazer {{ request.base_url }}mcp --header "Authorization: Bearer $env:SBT"; Remove-Item Env:SBT
Another assistant (not Claude Code)

Give it the address {{ request.base_url }}mcp (MCP over HTTP) and send the token as the header Authorization: Bearer <token>.

Try it

Start Claude Code, in any folder, and ask: “Using ShelfBlazer, which record types are there?” Then try “Add {{ ex_a }} called test-1”, and archive test-1 here afterwards.

It does not connect? Run claude mcp list: it should say Connected. If not, the token was probably mistyped or has expired: create a new one and repeat step 3, pasting the token rather than typing it.

Take care

What the assistant reads goes to your AI service’s account, so keep confidential things out of ShelfBlazer. Treat the token like a password: never paste it into a chat or a shared document. Read what the assistant proposes before you accept it, as you would a colleague’s. More in Help.
